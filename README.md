# Shimshal Heights

- `frontend/` Next.js 16 + React 19 (App Router) public website and the admin panel (`/admin`).
- `backend/` Express + MongoDB API (see backend/README.md).

## Run the frontend
    cd frontend && cp .env.example .env.local && npm install && npm run dev

Demo art is generated by `npm run demo-images` and is replaced by Cloudinary images later.

## Running the admin locally
    # terminal 1 (backend): set MONGODB_URI, JWT_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD, CLIENT_ORIGINS=http://localhost:3000, Cloudinary keys in backend/.env
    cd backend && npm install && npm run seed && npm run dev
    # terminal 2 (frontend): copy .env.example to .env.local (BACKEND_URL=http://localhost:5000)
    cd frontend && npm install && npm run dev      # then open http://localhost:3000/admin
The admin calls `/api/*` on its own origin and Next.js forwards it to the Express API (`rewrites`), so the httpOnly session cookie works without CORS or cross-site cookie settings.

## How the public site gets its data (Step 6)
* Server components read the API through `frontend/src/services/dataService.ts` (cached 60 s). When an admin saves content, the API calls the site's `/revalidate` endpoint so the change shows at once. Both sides need the same `REVALIDATE_SECRET` (16+ characters); without it the site simply refreshes every 60 s.
* The booking and contact forms call `/api/*` on the site's own address, which Next.js forwards to the API.
* Rooms without photos show a neutral "Photo coming soon" picture. Hero, about and call-to-action pictures come from the gallery (categories: Mountains & Nature, Shimshal Valley, Hotel Exterior).
* **Going live:** set `NEXT_PUBLIC_DEMO_MODE=false` so placeholder wording and fallback phone/email details disappear, and fill the hotel's real details in admin Settings. The About page's "Our story" and "Our hospitality philosophy" stay hidden until you add real text in `frontend/src/config/content.ts` (`aboutContent`).
* Working without the backend: `NEXT_PUBLIC_USE_MOCK=true` serves the built-in demo data.
